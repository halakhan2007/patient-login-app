# Patient Login App

## Project Overview

This project is a patient login application built using Python and Streamlit. It demonstrates a simple login interface and provides an opportunity to explore basic web app development with Python.

## Technologies Used

- Python
- Streamlit

## Features

- Patient login interface
- Interactive web app built with Streamlit

## Skills Demonstrated

- Python programming
- Building interactive applications with Streamlit
- Basic user interface development
